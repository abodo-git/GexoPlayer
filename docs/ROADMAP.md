# Roadmap

1. **v0.1** (done): basic player, playlist, shuffle/repeat, CI for Windows + Android.
2. **v0.2**: persist playlists (M3U import/export), drag-to-reorder, folder scan, tag/metadata and cover art.
3. **v0.3**: Android background playback + notification/media controls, Windows media keys and tray.
4. **v0.4**: 10-band equalizer, replay gain, crossfade/gapless tuning.
5. **v0.5**: spectrum/visualizer, mini mode.
6. **v0.6**: skin system (Winamp-style classic skin look) and themes.
7. **v1.0**: media library with search, installer (MSIX), Play Store release, signed builds.
