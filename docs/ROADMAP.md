# Roadmap

1. **v0.1** (done): basic player, playlist, shuffle/repeat, CI for Windows + Android.
2. **v0.2** (done): persisted state (playlist, position, volume, theme, EQ), compact volume control, Modern/Classic (Winamp-style) themes, 10-band equalizer with Winamp presets + preamp, drag-to-reorder, folder scan, M3U/M3U8 import/export, clear-with-Undo.
3. **v0.3**: Android background playback + notification/media controls, Windows media keys and tray.
4. **v0.4**: tag/metadata reading + cover art, replay gain, crossfade/gapless tuning, real signing keystore for Android.
5. **v0.5**: spectrum/visualizer, mini mode, app icon refresh, more Classic-theme fidelity (skin textures).
6. **v0.6**: full skin system (Winamp-style classic skin look) and theme editor.
7. **v1.0**: media library with search, installer (MSIX), Play Store release, signed builds.

## v0.3.0 (done)
Backend seam + fake backend, tags + cover art, search, sort, play-next queue, sleep timer, speed, mute, keyboard shortcuts. See docs/UPGRADE_PLAN.md for the phased plan (phases 2-7).
